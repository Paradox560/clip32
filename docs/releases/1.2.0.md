# Clip32 1.2.0 — performance and privacy update

This update reduces disk writes, keeps rich-text searching off the main thread, and removes unnecessary background polling. It includes the fixes from the efficiency and security audit.

- Store clip payloads separately from the history index, so pinning, reordering, and changing capacity do not rewrite the full history.
- Automatically migrate existing history while preserving clip contents, pins, ordering, and capacity.
- Cache parsed search text within a bounded budget, reuse filtered results during keyboard navigation, and reject stale search results.
- Bound plain-text title/preview work and cache rich-text presentation.
- Stop clipboard polling while capture is paused and refresh permission status when needed.
- Respect additional transient clipboard markers, cancel direct paste when clipboard contents change, and preserve focus after cancellation.
- Clean up interrupted-save snapshots and unreferenced payloads using conservative file checks.

## Install or update

Download `Clip32-1.2.0-universal.dmg`, open it, and drag Clip32 into Applications. The app supports Apple silicon and Intel Macs running macOS 13 or newer.

Quit Clip32 before replacing an existing installation. History and preferences are retained. Once history migrates, use version 1.2.0 or newer; older versions cannot read the new storage format. A changed ad-hoc signature may require removing and re-adding Clip32 in Accessibility settings.

## Signing status

This is a **preview release**, ad-hoc signed and **not notarized by Apple**. macOS may block a downloaded copy. Developer ID signing and notarization remain necessary for normal downloaded-app approval.

History stays local with owner-only file permissions and is not encrypted. There is no cloud sync or third-party runtime dependency.

## Validation

All 82 regression tests pass. Synthetic benchmarks reduced ten pin changes on a 16 MiB history from approximately 168 MB of logical writes to 28 KB. Warm searches across 256 rich-text entries improved from approximately 103 ms to 42 ms; cold parsing and row previews now run off the main thread. See the [full assessment](https://github.com/Paradox560/clip32/blob/v1.2.0/docs/audits/2026-11-07-efficiency-security.md) for methods, limits, and before/after measurements.

Both architecture builds and native demo rendering passed. The packaged DMG was mounted and checked for bundle identity, signature validity, and an exact executable match. A SHA-256 checksum is provided with the download.
